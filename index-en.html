Pizza Menu

Introduction: This is a single-page application for a pizza menu, built with the React framework. Its primary purpose is to display the restaurant's menu and operating hours.

Technologies Used: React, HTML, CSS, JavaScript

Project Highlights:
  • React Foundation: The project was set up using Create React App.
  • Theme Switching: Implemented a light/dark mode toggle, with user theme preferences saved in localStorage.
  • Dynamic Content Display: Shows operating status based on the current time (open from 16:00 to 21:00).
  • Data-Driven UI: Menu items are dynamically rendered from the pizzaData array.
