MY SKILLS

DESIGN

理解網頁設計不僅追求美觀，更重視使用者體驗與資訊傳達清晰。

以珠寶購物網站為例：

  1. 簡約的白色背景，引導顧客目光集中於產品。
  2. 清晰的左側產品分類，協助顧客快速定位所需商品。
  3. 透過麵包屑導航，讓顧客能一目瞭然產品的分類歸屬，提升操作便利性。

CODING

  1. 熟悉 HTML / CSS & SCSS JavaScript，具備網頁切版與互動功能實作能力。
  2. 使用 Bootstrap、Animate.css、Google Fonts 強化排版與視覺動效。
  3. 能使用 @media 與 Bootstrap Grid 製作響應式版型，適應各種裝置。
  4. 熟悉 Git 基本操作，了解版本控制與多人協作概念。
  5. 運用 photoshop 基礎功能修圖/除去背景 產生gif動圖。

IDEA

從使用者角度思考問題，樂於探索新工具與技術， 具備主動學習與分析解決問題的能力。

  1. 持續精進 React 等框架應用。
  2. 積極探索 UI/UX 設計趨勢
  3. 未來計畫學習運用 Figma 等工具進行視覺化呈現。
