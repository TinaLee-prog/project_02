簡  介：查詢台灣農村地區美食小吃的網頁平台

專案亮點：
  • API 串接：串接政府開放資料 API，自動取得小吃資料，提高資料的即時性與準確度。
  • 整合 Google Map：一鍵導向 Google 地圖，使用者能迅速查找店家位置，提升便利性與 UX。

披薩菜單

簡  介：這是一個使用 React 框架打造的披薩菜單單頁應用程式，主要展示餐廳菜單和營業時間資訊。

使用技術：React、HTML、CSS、JavaScript

專案亮點：
  • React 基礎架構:使用 Create React App 建立專案
  • 主題切換功能: 實現 light/dark 模式切換並用 localStorage 保存用戶主題偏好
  • 動態內容顯示: 根據當前時間顯示營業狀態 (16:00-21:00 營業)
  • 資料驅動 UI: 從 pizzaData 陣列動態渲染菜單項目

DESIGN

理解網頁設計不僅追求美觀，更重視使用者體驗與資訊傳達清晰。

以珠寶購物網站為例：

  1. 簡約的白色背景，引導顧客目光集中於產品。
  2. 清晰的左側產品分類，協助顧客快速定位所需商品。
  3. 透過麵包屑導航，讓顧客能一目瞭然產品的分類歸屬，提升操作便利性。

CODING

  1. 熟悉 HTML5、CSS3 / SCSS，具備良好的切版能力與互動功能開發經驗。
  2. 精通 CSS Flexbox 與 Grid，能配合 @media 製作響應式網頁。
  3. 運用 JavaScript，具備串接 API 的能力，提升網頁資料的即時性與互動性。
  4. 善用 Bootstrap 與 Google Fonts 增強排版與視覺表現。
  5. 具備 Git 操作經驗，理解版本控制與團隊協作流程。
  6. 能進行簡易 Photoshop 圖像處理，支援網頁素材與動畫製作。

IDEA

  2. 積極探索 UI/UX 設計趨勢

關於我

您好！我是一位從業務助理轉職前端開發的學習者，熱衷於將想法轉化為實際且有影響力的網頁作品。

過去擔任業務助理的經驗，讓我深知「良好溝通與細心協作」的重要性，也培養了對「使用者需求的敏銳洞察力」。這些經驗讓我更加相信，一個有意義的網頁，不只追求美觀與功能，更在於能真正解決問題、服務大眾。

前端開發賦予我實現這份願景的機會。透過程式碼，我能將設計理念化為視覺，創造出能被廣泛看見、並為人們帶來便利的數位產品。這種「透過我的參與，讓作品被世界看見」的成就感，正是我對工作與人生的期許。

為此，我全心投入前端學習，並實作了多個網頁作品。希望透過這個網站，讓您更了解我的能力與作品思維。我期待有機會能與您交流，共同打造更多精彩的網頁，並成為貴團隊的一份子。
